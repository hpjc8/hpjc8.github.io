# 前言

为什么有这个网站？

有一天，站长又读完了一本书，正做着摘抄。忽然想到，假如我把我摘抄的内容，放到网站上怎样？反正我网站上什么也没有，于是乎就诞生了这个网站

站长呢也希望通过这个网站，与你们共同分享，共同提升，共同进步，养成积累的好习惯！

# 《风会记得一朵花的香》

## 写景&物

- “树顶上就会悬上红形形的果实，一撮一撮，如点亮一盏盏的红灯笼，华丽得不像样子”

- “一区里有凌霄花长廊。这几天花开得正盛，橘红色的花朵，小唢呐一般，天天在草绿色的枝叶间，鼓着小腮帮吹呀吹呀，吹奏着婚礼进行曲”

- “热辣辣的花朵，把树枝都烧红了”

- “如檐前开得好好的一蓬大丽花，花艳丽得快撑不住颜色了，如门前的大槐树上，蹲着的那个喜鹊窝，一只花喜鹊盘踞在上面唱着歌”

- “老人的屋后，是鸢尾花的天下，蝴蝶一样的鸢尾花，扑闪着紧色的大翅膀，在人的心中，扇动起一圈一的温柔”

- “不远处，丝瓜花趴在一垛草堆上窃笑，南瓜藤攀爬到一棵桐树上”

- “它们时不时地，会溜进教室听课。听得不耐烦了，尾巴一甩，走
  啦（猫）”

- “夜深，世界孤寂成一顶帐篷。蜡在流泪，一滴一滴，溅落到他的字上，凝固成冰冷的花朵。红的，白的，如敛翅的蝴蝶”

- “春天来的时候，大地在一夜间换了新装，绿，绿不尽的绿。河边的白茅们“唰”的一下，挥出尖尖的小脑袋来”

- “凤仙花好长，种子掉在哪里，哪里就能长出一大片，你追我赶地长，一心一意地长”

- “冬天的阳光，见缝插针地，从高楼的缝隙里，漏下一点两点来”

- “废弃的百年院落，墙上爬满绿，地上的砖缝里渗着绿。屋顶上，继绣着绿”

- “春风轻拂，勾起了墨绿色的柳絮，卷起了娇艳欲滴的繁花，轻柔地飘落在课桌的语文书上”

## 写人

- “高高的个头，白净的皮肤，有着黑色的或淡黄的微卷的发。深凹进去的大眼睛，炯炯的。浑身蓬勃着年轻人特有的朝气，像只拔节而长的笋”

- “他的声音挟裹着风雪，挟裹着草原的莽莽苍苍，撞进我的耳里来，如暗夜里的埙”

- “他着格子衬衫，穿尖头皮鞋，操一口流利的普通话，…………，他有一双小鹿似的眼睛，清澈、温暖”

- “他的课，上得丰富多彩。一个个汉字，在他嘴里，都成了妙不可言的音符”

- “我们的眉梢间，已爬上岁月的皱纹”

## 写哲理

- “人生如寄，岁月匆匆，我们只有更珍惜活着的当下，珍惜这胸膛里跳动着的一颗心，狠狠把这个世界爱上，才不枉活过一场”

- “岁月，原是由许许多多的从前组成的，山是有从前的，庙是有从前的，老和尚是有从前的，小和尚亦早已成了从前的从前”

- “当年不曾以为意的，日后却念念不忘，只因为啊，从前的青春年少，我们再也回不去了”

- “当下愣住，一个人的存在，到底对谁很重要？这世上，总有一些人记得你，就像风会记得一朵花的香。风来尘往，莫不如此”

- “它早已在我的记忆里生了根，从未走远；一个天地都是静的．思绪可以放牧得很远；我对着它们看，心中轻轻淌过一条岁月的河”

## 写情感

- “我静静听，我听见孤独，像一只流浪的小狗，呜咽着（孤独）”

# 《听风八百遍，才知是人间》

## 写景&物

- “又是秋天，姝妹妹推我去北海看了菊花。黄色的花淡珀雅．白色的花高洁，紫红色的花热烈而深沉，泼泼洒洒，秋风中正开得烂漫。”

- “我们家后面那个"花园"也是他管的。蔬菜，各样的，是他种的。每天浇，摘去焦枯的叶子，厨房要用时采，都是他的事。花也是他种的，有月季．有山茶，有玫瑰，有红梅与蜡梅，有美人蕉，有桃，有李，有不开花的兰，有葵花，有蟹爪菊，有可以染指甲的凤仙，有比鸡鸡冠大到好几倍的鸡冠。关于每种花他都有不少话讲：花的脾，花的胃，花的颜色，花的这样与那样。梅花有单瓣双瓣，兰心有荤心素心，山茶有家有野，这些简单，但小孩儿时听来有趣的知识，都是他教我们的。”

- “还有寂寓寞的瓦片风筝，没有风轮，又放得很低，伶仃地显出惟悴可怜的模样。但此时地上的杨柳已经发芽，早的山桃也多吐蕾，和孩子们的天上的点缀相照应，打成一片春日的温和”

- “说起冬天，忽然想到豆腐。是一"小洋锅"白蔗豆腐，热腾腾的。水滚动着，像好些鱼的眼睛．一小块一小块豆腐养在里面，嫩而滑，仿佛反穿的白狐大衣。”

- “有点风，月光照着软软的水波波；当间那一溜儿反光，像新砑的银子。湖上的山只剩了淡淡的影子。”

- “我在小小的书斋里，焚起一炉香，袅袅的一缕烟线笔直的上升，一直戳到顶棚，好像屋里的空气是绝对的静止，我的呼吸都没有搅动出一点波澜似的。”

## 写人

- “我看见他戴着黑布小帽，穿着黑布大马褂，深青布棉袍蹒跚地走到铁道边，慢慢探身下去，尚不大难。”

- “他用两手攀着上面，两脚再向上缩；他肥胖的身子向左微倾，显出努力的样子。”

- “我读到此处，在晶莹的泪光中，又看见那肥胖的，青布棉袍黑布马褂的背影。”

- “丝绒碗帽，正中缀一方白玉，曲襟背心，花缎袍子，后面挂着胖辫子，底下缎带扎脚管，双梁厚底鞋子，头抬得很高，英俊之气，流露千眉目间”

- “卷发，白的上衣，白的长裙拖着地面，腰身小的一把，两手举起托着白后头，头向后歪侧，眉峰紧蹙，眼波斜睇，正是茶花女自伤命薄的神情。”

- “他那唱的音调就像是在厅的顶梁上绕着，又像是暖天细雨细下雨似的在你身上匀匆的酒，反正听着心里就觉得舒服。”

- “家德在他娘的跟前，拖着显早过半百的年岁，身体活灵像得像个一只小松鼠，忙着为她张罗这样那样的，口齿伶俐得像一只小八哥，娘长娘短的叫个不住”

- “当我忙得忘了许多事，甚至于忘了她，这两只眼会忽然在一朵云中，或一汪水里，或一瓣花上，或一线光中，轻轻地一闪，像归燕的翅儿，只需一闪，我便感到无限春光。”

- “看我一眼，她低头着头轻快地走过去，把一点微笑留在她身后的空气中，像太阳落后还留下一些明霞”

- “春在燕的翅上，把春光颤得更明了一些。同样，我的青春在她的眼里，永远使我的血温暖．像土中的一颗子粒，永远想发出一个小小的绿芽。”

- “于是二十年来毫不忆及的幼小时候对于精神的虐杀的这一幕，忽然地在眼前展开，而我的心也仿佛同时变成了铅块，很重很重的堕下去了。”

- “我仍搅着杯子，也许飘流久了的心情，就和离了岸的海水一般，若非遇到大风是不会翻起的……弟弟再向我说什么我已不去听清他，仿佛自己是沉坠在深远的幻想的井里”

## 写心理

- “但这等感想的出现非常短促又模糊，像飞鸟的黑影在池上掠过一般，真不过数秒间在我心头一闪，过后就全无其事”

- “在热闹的地方，忙碌的时候，我这种疑惑与悲哀也会被压抑在心的最底层，而安然地支配取舍各种事物，不复作如前的痴态……一到静僻的地方，孤独的时候最是夜间，它们又全部浮出在我的心头了。”

## 写哲理

- “我们生而破碎，用活着来修修补补”

- “燕子去了，有再来的时候；杨柳枯了，有再青的时候；桃花谢了，有再开的时候。但是，聪明的，你告诉我，我们的日子为什么一去不复返呢？——是有人偷走了他们罢：那是谁？又藏在何处呢？是他们自己逃走了罢：现在又到了网哪里呢？”

## 写情感&感悟

- “母亲生前没给我留下为过什么隽永的机哲言，或要我恪守的教诲，只是她去世之后，她艰难的命运、坚忍和毫不张扬的爱，随光阳流转，在我的印象中愈加鲜明深刻。”

- “我放下书，想，这么大一座园子，要在其中找到她的儿子。母亲走过了多少焦灼的路。多年来我头一次意识到，这园中不单是处处都有过我的脚印车辙，有过我的车辙的地方．也都有过母亲的脚印。”

# 《昆虫记》

## 写景&物

- “矢车菊，全都是一副桀骜不驯的样子，浑身长满了刺，或者长满了棘……各种各样的矢车菊相互交织，彼此纠缠，乱糟糟地簇拥在一起，其中可见一种菊科植物，形同枝形大烛台似的支棱着，凶相毕露，被称之为西班牙刺格，其枝杈末梢长着很大的橘红色花朵，似火焰一般，而其刺茎则是硬如铁钉”

- “黄莺在丁香树丛中筑巢搭窝;翠鸟在柏树那繁茂的枝叶间落户安家;麻雀把碎皮头和稻草麦秆衔到屋瓦下;南方的金丝雀在它们那建在梧桐树档的没有半个黄杳大的小安乐窝里鸣叫;红角鹗习惯了这儿的环境，晚间飞来唱它那单调歌曲，声似笛音;被人称之为雅典娜鸟的猫头鹰也飞临此地，发出它那刺耳的咕咕声响”

- “这些蓟类植物之间的空地上，爬着荆棘的新枝丫，结着淡蓝色的果实，枝条长长的，像是长着刺的绳条。”

- “四下里矗立着一座座狼牙棒似的金字塔，伊利里亚矢车菊投出它那横七竖八的标枪来。”

- “它们当中，有专以捕食活物为生的“捕猎者”，有以湿土“造房筑窝者”，有梳理绒絮的“整理工”，有在花叶和花蕾中修剪材料备用的“备料工”，有以碎纸片建造纸板屋的“建筑师”，有搅拌泥土的“泥瓦工”，有为木头钻眼的“木工”，有在地下挖掘坑道的“矿工”，有加工羊肠薄膜的“技工”……还有不少干什么什么的，我也记不清了。”

- “白袍墨翅的鹤鸰鸟，宛如身着多明我会服装的修士，栖息在最高的石头上，唱着它那井不动听的小曲短调。”

- “五月里，夜幕隆临之后，这个大池塘就变成了一个大乐池，各种鸣声交织，震耳欲聋，以致你若是在吃饭，就甭想在饭桌上交谈，即使躺在床上，也难以成眠。”

- “我在我的荒石园里漫步思索，一棵樱桃树吸引了我的视线，它在池塘畔舒枝展叶，春天繁花如雪，现在则挂满了鲜艳欲滴的红樱桃:成群的麻雀叽叽喳喳地坐在树枝上大吃特吃;胡蜂咬破薄薄的果皮，小口吮吸着甜汁;花金龟美滋滋地吃饱睡熟了;小飞蝇醉倒在流淌着果浆的饭桌上.....樱桃核掉在树下，一直眼巴巴看着的地面居民们立刻行动起来，蚂蚁、蛞蝓把果核上的残肉一点点啃净，田鼠们忙着把光溜溜的果核搬回洞里储存，冬天它们会咬开硬壳，吃里面的果仁。”

## 写哲理

- “螳螂那些密密麻麻的小卵，只有很少一部分用来繁衍后代，其他都将进人大自然的食物链，为了开始而结束，为了新生而死亡”

- “能使这种可以组织起来的材料具有薄纱状，并让脉序构成一个难以绕出的迷宫，势必有比模具更巧妙更高级的结构，势必有一张标准的平面图，有一个让每一个原子进人规定位置的理想的施工说明书，……，蝗虫翅膀这个从不起眼的外套中挣脱出来的美丽的花边薄翼，让我们知道了有另一位建筑师，它画出了一些平面图，生命则按它们去建造”
